# Nathaniel Maisango — Professional Portfolio

A responsive starter portfolio built with HTML, CSS, and JavaScript.

## Sections
- About and education
- AI training and evaluation
- Software and data skills
- Digital marketing
- Virtual assistance
- Project cards
- Contact links

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a new public repository, for example `nathaniel-maisango-portfolio`.
3. Upload `index.html`, `styles.css`, `script.js`, and this README.
4. In repository Settings, open Pages.
5. Select deployment from the `main` branch and the root folder, then save.
6. Follow the Pages screen for the published URL.

## Important before publishing
- Review all personal/contact information.
- Replace starter project ideas with projects you have completed and can explain.
- Add real screenshots, repository links, sample outputs, and brief lessons learned.
- Do not claim hypothetical results as real client outcomes.
- Do not upload confidential client information or private assessment material.
- Add a CV download only after adding the final CV file.
